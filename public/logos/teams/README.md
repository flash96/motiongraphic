# Logo Tim

Taruh logo tim-tim Liga 1 di sini.

**Penamaan file:** gunakan nama pendek, lowercase, tanpa spasi.
Contoh:
- `persib.png`
- `persija.png`
- `arema.png`
- `psis.png`
- `bali-united.png`
- `pss.png`
- `borneo-fc.png`
- `madura-united.png`

**Format:** PNG transparan, ukuran minimal 256×256 px.
**Rekomendasi:** 512×512 px supaya tajam di video 1080p.
