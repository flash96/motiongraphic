# Brand Logo

Taruh file logo brand kamu di sini.

**File yang sudah ada:**
- `logo.png` — logo utama (dari upload)

**Yang dibutuhkan:**
- `logo.svg` — versi SVG (opsional, tapi lebih tajam untuk video)
- `logo-white.png` — versi putih/monokrom untuk background terang (opsional)

**Format:** PNG transparan atau SVG. Hindari background solid.
