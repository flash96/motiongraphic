# Foto Pemain

Taruh foto pemain di sini. Dipakai untuk scene Man of the Match dan berita transfer.

**Penamaan file:** lowercase, gunakan strip.
Contoh:
- `david-da-silva.png`
- `ciro-alves.png`
- `nick-kuipers.png`

**Format:** PNG transparan (cutout tanpa background) paling ideal.
JPG juga bisa tapi akan ada background kotak di video.

**Ukuran:** minimal 400×500 px (portrait crop).
