# Font

Taruh file font di sini.

**Font yang dibutuhkan:**

1. **Bebas Neue** (display/headline)
   - Download: https://fonts.google.com/specimen/Bebas+Neue
   - File: `BebasNeue-Regular.ttf`

2. **Inter** (body text)
   - Download: https://fonts.google.com/specimen/Inter
   - File: `Inter-Regular.ttf`, `Inter-Bold.ttf`, `Inter-SemiBold.ttf`

**Cara download dari Google Fonts:**
1. Buka link di atas
2. Klik "Download family"
3. Extract zip, copy file .ttf ke folder ini
